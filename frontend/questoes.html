📄 Importar Questões de PDF (OCR)

Envie um PDF com questões numeradas e gabarito. O sistema extrai o texto (digital ou via OCR para escaneados) e cadastra automaticamente.

ℹ️ Formato esperado do PDF
Questões numeradas:
1) Texto do enunciado...
A) Alternativa A
B) Alternativa B
C) Alternativa C
D) Alternativa D
E) Alternativa E

Gabarito (no mesmo PDF):
GABARITO
1-A 2-B 3-C 4-D 5-E ...

Formatos aceitos: "1. ", "1) ", "Questão 1", "QUESTÃO 1"
Para PDFs escaneados, o Tesseract OCR será usado automaticamente.

🌐 Importar Questões via URL

Cole o link direto do PDF da prova (de sites como Gabarite, PCI Concursos, Cebraspe). O sistema baixa e importa automaticamente.

ℹ️ Links recomendados para PC-MA / Perito CESPE
Sites com provas gratuitas:
• PC-MA 2018 — Perito Criminal (CESPE)
• Todas as provas PC-MA
• PCI: Provas Perito Criminal (várias PCs)
• Todas as provas CESPE

Dica: Clique em "Baixar Prova" no site → copie a URL do PDF que abrir → cole acima.

📥 Importar Questões via CSV

Envie um CSV exportado do QConcursos ou Gran Cursos. O formato é detectado automaticamente pelos cabeçalhos.

ℹ️ Formatos esperados
QConcursos:
Disciplina, Assunto, Banca, Ano, Enunciado, A, B, C, D, E, Gabarito

Gran Cursos:
Matéria, Tópico, Questão, Alternativa A, Alternativa B, Alternativa C, Alternativa D, Alternativa E, Resposta, Banca, Ano

Limite: 5.000 questões por importação. Duplicatas (mesmo enunciado + banca) são ignoradas.
